# 项目章程：AI 小说动态漫改编工作台

## 立项目标

建立一套面向中国大陆小型动态漫/漫剧工作室的 SaaS 工作流，把用户已有的小说或故事转化为可编辑、可追溯的剧本、设定与分镜，并为后续图片和视频生成提供结构化输入。

## 问题陈述

小说中的环境、心理、世界观与叙事信息不能直接交给视频模型。当前工作通常依赖创作者手工完成内容理解、剧本改编、视觉设定、分镜拆解和提示词编写，流程耗时、容易遗漏，且人物和设定难以跨章节保持一致。

## 产品承诺

用户导入一章小说或一个故事片段后，可以得到：

1. 可核对原文出处的人物、场景、道具、事件和世界规则。
2. 可编辑并确认的场次剧本。
3. 可复用的角色、场景、道具与画风设定。
4. 可编辑的结构化分镜。
5. 可带走的剧本、分镜和设定资料。

## MVP 纵向切片

```text
导入一章小说
→ 识别章节和原文片段
→ 提取故事知识
→ 用户确认
→ 生成场次剧本
→ 显示原文与剧本映射
→ 生成 20～40 个分镜
→ 导出剧本与分镜
```

## MVP 范围

### 包含

- TXT、DOCX 或粘贴文本导入
- 章节与段落识别
- 人物、场景、道具、事件和世界规则提取
- 原文证据与置信状态
- 场次剧本生成、编辑、确认和锁定
- 角色、场景、道具和全局画风设定
- 结构化分镜及预计时长
- 剧本、分镜和素材导出

### 不包含

- AI 故事或小说原创
- 自动续写
- 小说发布或连载
- 整本小说一次自动影视化
- 120 分钟电影一键生成
- 图片或视频生成
- 自由节点画布
- 专业非线性剪辑器
- 自建基础模型或 GPU 集群
- 原生移动 App
- 多人实时协作

## 初始目标用户假设

第一批用户是中国大陆 1～10 人的小型短剧或漫剧工作室。他们需要把已有网文或故事转成可继续制作的影视剧本、设定与完整分镜。

## 成功指标

- 用户可以在 30 分钟内从一章原文获得第一版可编辑剧本。
- 核心人物和关键事件可追溯至原文。
- 用户能在局部重生成时保留已锁定内容。
- 从导入到导出形成一条可完成的纵向流程。
- 试用用户愿意使用该流程完成第二个项目。

## 质量指标

- 核心情节覆盖率
- 人物及场景遗漏率
- 虚构重要事实率
- 提前剧透率
- 分镜时长偏差
- 单镜头可用率
- 平均重试次数
- 每成片分钟的模型成本

## 原则

- 原文永久保留且可追溯。
- AI 输出默认是候选内容，不自动成为故事事实。
- 用户确认和锁定优先于模型建议。
- 修改上游内容只标记下游受影响项，不自动产生费用。
- 文本、图片和视频模型均通过可替换适配层接入。
- 首版优先验证完整工作流，不追求功能数量。

## 主要风险

- 长篇解析在层层摘要中丢失重要事实。
- 人物别名、隐藏身份和时间线被错误合并。
- AI 改编偏离原著或过度压缩环境内容。
- 第三方模型调价、限流或下线。
- 小说版权、真人肖像、声音与生成素材授权不清。
- 用户愿意尝试但不愿持续付费。

## 已确认产品决策

- 首发市场：中国大陆。
- 第一批核心用户：1～10 人的小型短剧或漫剧工作室。
- MVP 单次输入：一章，最多约 20,000 字。
- MVP 交付终点：可编辑剧本、角色/场景/道具设定和完整分镜。
- 默认采用平衡改编：允许压缩描述和合并场次，但不得改变核心故事事实。
- MVP 不生成图片或视频，只为后续生产提供结构化资料。
- 首版制作类型：AI 动态漫/漫剧。
- 用户指定目标单集时长，AI 根据剧情建议拆分为一集或多集。
- 故事知识、剧本、设定和分镜必须逐阶段确认。
- 合并人物、删除重要事件或重排事件等重大改编必须逐项批准。
- 每段对白、动作和分镜必须关联来源原文；AI 新增内容必须明确标记。
- MVP 支持邀请成员，但不支持多人同时编辑。
- MVP 支持粘贴文本、TXT 和 DOCX 导入。
- 单集时长提供 1、3、5 分钟三个预设。
- 项目创建时选择 9:16 竖屏或 16:9 横屏。
- 用户在生成前选择旁白型或对白型叙事。
- 环境与心理描写分类转成环境镜头、动作表演、声音或旁白，并记录转换方式。
- 角色、场景和道具输出可供分镜使用的文字设定卡。
- 分镜包含画面、人物、动作、对白/旁白、预计时长、景别、机位、运镜、声音、情绪及资产引用。
- 首版导出 DOCX 剧本、XLSX 分镜和 JSON 完整结构化数据。
- 剧本采用动态漫结构化格式：场次标题、环境、人物、动作、对白、旁白和声音。
- 设定卡面向分镜生产，包含可见特征、状态变化和使用限制。
- 提供可编辑的全局画风预设。
- 分镜按视觉焦点、人物动作、情绪和信息变化拆分，再计算时长。
- 成员提交修改建议，由项目负责人统一接受或拒绝。
- 修改已确认内容时创建新版本并列出受影响项，由用户决定是否重新生成。
- MVP 验收目标：核心事件覆盖率不低于 90%，不得虚构核心事实，所有内容可追溯，成片规划时长偏差不超过 10%。
- 一个项目代表一部作品，可逐章导入；MVP 每次最多处理一章。
- 项目角色包括负责人、编辑和审核人。
- 人物别名或隐藏身份不确定时必须展示证据并等待用户确认。
- 重新导入章节时创建原文新版本、显示差异并标记受影响内容。
- AI 部分失败时保留成功结果，只重试失败部分。
- 支持单条故事知识、单个场次、单项设定和单个分镜的局部重新生成。
- 冲突事实并列保存并交由用户判断其性质，不由 AI 自动覆盖。
- 首版支持手机验证码与微信扫码登录，并允许绑定同一账号。
- 上传作品前用户必须声明拥有作品或合法改编权。
- 用户作品默认不用于训练；主动授权必须独立、可撤回。
- 删除项目进入 30 天回收站，期满删除业务数据和文件，备份按已公示周期过期。
- 收费采用月度订阅包含额度，超出后按 AI 积分计费。
- 平台默认自动选择文本模型，高级版允许绑定用户自己的 API Key。
- AI 任务在后台运行，显示阶段进度并在完成后发送站内通知。
- 不超过 20,000 字的一章内容，每个 AI 阶段通常应在 5 分钟内返回。
- 每项 AI 任务向用户展示固定或预估积分，后台记录实际模型成本。
- 提交任务时冻结预计积分，按成功完成部分结算，失败部分自动退回。
- BYOK 用户仍需高级订阅，但对应调用不消耗平台模型积分。
- 上传内容经过自动合规扫描；受限任务需说明原因并提供申诉入口。
- 版权投诉期间暂停相关项目生成和分享，依据授权证明决定恢复或下架。
- 中国大陆用户作品默认存储在中国大陆区域。
- 系统审计导入、修改建议、确认、锁定、重新生成、导出和删除等关键操作。
- 项目彻底删除后，备份最长保留 90 天并按周期覆盖。
- 用户可以查看所有流程阶段，但只有上一步确认后才能生成下一阶段正式内容。
- 原文与剧本/分镜采用左右双栏，点击内容时高亮对应关系。
- 负责人和审核人可以确认阶段结果。
- 修改建议包含替换内容和修改理由，由负责人或审核人接受或拒绝。
- 角色设定包含可见特征、行为习惯、当前状态、状态变化和禁止表现。
- 场景设定包含空间、时代、天气、光线和色调；道具设定包含外观、材质、尺寸、持有人和剧情作用。
- 分镜编辑采用左侧镜头列表/表格、右侧当前镜头详情。
- 多章节文件导入后识别目录，用户每次选择一章处理，其余章节保存在项目中。
- 移动端只支持进度查看、审核、建议处理和通知，不承担完整编辑。
- 桌面端保留追溯、审核、分镜三种工作模式；用户可以自由切换，三种模式共享同一份项目数据与流程状态。
- 免费试用最多处理 3,000 字，并生成受额度限制的剧本、设定和分镜。
- 首版套餐为免费试用、工作室版和含 BYOK 的高级工作室版。
- 付费套餐限制成员数量和每月 AI 积分，普通文档编辑与导出不额外收费。
- 首次发布邀请 5～10 家目标工作室参与封闭内测。
- 验证成功标准：至少 5 家完成完整流程，其中 3 家在 14 天内处理第二个项目或章节并愿意付费。
- AI 质量回归样本覆盖玄幻、都市和悬疑，且必须是授权或自有内容。
- DOCX 包含项目说明、拆集大纲、剧本和设定；XLSX 按集建立分镜工作表；JSON 保存全部数据和追溯关系。
- 需求确认后的下一阶段是低保真交互原型，不直接开始代码开发。

## 当前阶段

项目已立项，需求基线 v0.1 已于 2026-09-21 确认并锁定。低保真原型已确认保留追溯、审核、分镜三种工作模式；当前继续验证模式切换与上下文连续性，不进入正式代码开发。

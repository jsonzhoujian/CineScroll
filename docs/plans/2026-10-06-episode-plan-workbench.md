# 拆集方案持久化与审核工作台

确认范围：T06 拆集方案版本/上游引用持久化、认证读取/裁决/确认 API、审核页时长/核心事件/原文范围展示。基线 73376e0。不扩展剧本正文生成，不调用真实模型、不推送。

测试边界：ScriptService/PostgresScriptRepository 的版本保存与 CAS；会话认证 HTTP 读取/裁决/确认；浏览器原文追溯与逐项裁决。采用红绿迭代及 Standards/Spec 双轴复审。

步骤：
1. 增加领域读取与上游复核，拒绝未确认故事知识及过期候选确认。
2. 新增拆集版本、活动头、操作幂等记录的 PostgreSQL 仓储与迁移；RLS、不可变版本、短事务锁、上游基准及 CAS。
3. 只读/裁决/确认 API。生成结果通过已有可信 EpisodePlanRunner 保存，不开放客户端伪造 AI 结果的写入接口。
4. 已确认知识后展示拆集审核：明确读取，列出单集时长、原文证据及事件引用；重大改编逐项决定，负责人/审核人正式确认，编辑只读。
5. 临时库、HTTP、浏览器回归，类型检查及复审，本地提交。

生成任务/供应商传输及正式生产装配不在本轮；空候选显示待生成，不用虚构数据补位。持久层迁移仅在全新临时测试库验证，不迁移业务数据库。

实现完成：复用专用临时 PostgreSQL（此前局部重试测试库、非业务库）验证新迁移可重跑、重建读取、并发 CAS、租户隔离、编辑确认拒绝、上游原文拒绝、幂等结果及正式头保护。领域回归先证实旧知识候选可被确认，再补上游复核为绿。API及浏览器按认证/审核边界完成红绿。

最终验证：Node 165 通过、10 跳过、0 失败；新增 PostgreSQL 拆集专项独立运行通过。浏览器 25 项通过（含正常拆集审核、编辑只读、过期、空候选及原有任务/导入）；受影响包类型检查和 diff 检查通过，页面截图已人工检查。

双轴复审：Spec 无阻断；Standards 发现受限编辑可清空正式头的 P2，已实库复现红灯并修复；同时禁止正式方案回退并要求候选推进父版本一致。复核无剩余阻断。无真实模型、业务数据库迁移或生产装配；临时服务在最终验证后停止。

# 账本数据库只读启动预检

用户确认：公开初始化/预检接口 + 真实隔离数据库测试；检查受限登录、有效角色、权限、强制RLS、迁移/索引和历史保护触发器，失败拒绝初始化并净化错误。只读，不迁移或授权，不做服务身份授权，不接扣费。

实现 `assertCreditLedgerDatabase(pool)` 与 `createCheckedCreditLedgerRepository(pool)`。后者只在预检成功后返回仓储，仍由调用方管理Pool。旧构造器是低层未预检入口，不改现有夹具；未来生产装配必须走受检入口。

采用READ ONLY事务、5秒语句超时及pg_catalog搜索路径，仅读元数据和LIMIT0确认列。校验两表严格scope策略（拒绝额外策略）、表/列最小权限、登录/有效角色危险属性和额外成员资格、有效主键/必要约束、触发器事件类型和已知函数源指纹。指纹用于迁移漂移检测，不是抵抗恶意数据库管理员的证明。

TDD切片：

1. 连接故障返回稳定BILLING_DATABASE_NOT_READY；先红后绿。
2. 隔离管理员测试库创建随机受限登录，健康受检初始化成功且不写业务记录；管理员或缺表被拒绝。
3. 一项一项验证禁用触发器、错误保护函数、未强制RLS、宽泛策略、危险列权限、额外成员角色、缺少索引/约束等，测试管理员恢复夹具；预检不自行修复。
4. 完整回归/类型检查/双轴评审后本地提交。实库预检测试使用独立TEST_BILLING_READINESS_DATABASE_URL，须单独或test-concurrency=1运行，不与其他DDL测试并行。

不验证网络TLS/凭据配置、备份、生产身份/证据或支付，也不持续监控管理员之后的DDL变更；这些仍是部署前置事项。

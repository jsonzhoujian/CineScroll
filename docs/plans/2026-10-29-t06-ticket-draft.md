# T06 剩余纵向任务草案

状态：用户于 2026-10-29 确认粒度与依赖，已发布为[六个独立任务](../../.scratch/novel-adaptation-mvp/issues/README.md)。本文件保留获批拆分依据，执行状态以独立任务为准。

## 已有基础与边界

T04/T05 已按任务记录完成。拆集方案已有持久化、审核、后台任务、原生传输和默认关闭的受控生产装配；本轮不重复建设。正式剧本已有领域服务、模型端口、候选编辑、建议、确认、锁定和质量规则引擎。仍需持久化、服务装配、任务执行和用户操作闭环。

权威输入为产品规格第 3、7～9、12 节、领域词汇、canonical 契约及 T06 原验收条件。实现须先检查这些输入及现有服务，复用已有边界。用户于本轮确认编辑仅提交建议；负责人和审核人可直接编辑候选；正式修改派生候选重新确认，锁定先解锁。

以下每项均包含所需存储、权限、API、UI 和有意义的测试，不拆成纯水平层。发布时一项一个文件，采用本地 tracker 的 ready/blocked 状态，保持原 T06 为未完成父项。

## 01 — 从确认拆集生成并追溯首份剧本候选

Blocked by：无新增任务；T05 和现有拆集基础已交付。

用户在确认当前拆集后提交剧本生成任务，离开页面后仍可查看状态，显式加载持久化候选并点击对白或动作查看原文依据。

- [ ] 服务端绑定当前原文、已确认故事知识、已确认拆集及生成参数，拒绝旧上游与未批准重大改编；不接受客户端伪造上下文。
- [ ] 通过既有任务基础和受控供应商边界执行；请求幂等，未知执行先恢复核对、不再次付费调用；断线或重启不丢失候选及任务结果关联。
- [ ] 场次和元素持久化为不可变候选；成功项和失败 scope 分开保留，显示部分成功状态。
- [ ] 显式加载校验结果归属及当前上游；对白、动作有有效原文引用或批准的改编新增，转换类型可查看。
- [ ] 跨租户隔离、并发提交、上游变化、重启恢复和浏览器演示通过；真实模型调用及生产启用仍由独立发布门禁控制。

## 02 — 审阅候选、编辑文本并处理修改建议

Blocked by：01。

用户刷新后仍能继续审阅同一候选；负责人和审核人直接编辑候选，编辑成员提交替换内容与理由，获授权者接受或拒绝。

- [ ] 建议及处理结果持久化，界面与 API 共同执行统一权限，越权请求不改变内容。
- [ ] 修改创建新版本并保留证据、转换类型、场次及失败项；记录操作者、时间、理由和请求身份。
- [ ] 建议处理幂等；旧版本或目标文本变化返回冲突，不覆盖他人工作。
- [ ] 追溯与审核切换保留章节、集、场次、元素和原文定位，内容版本不因切换而改变。
- [ ] 重启恢复、三角色正反例、并发冲突及浏览器操作通过。

## 03 — 仅重试剧本失败范围

Blocked by：01；不依赖 02。

用户选择可重试失败项重新生成，成功元素继续保留，界面明确本次成功与剩余失败范围。

- [ ] 服务端限制 scope 为当前可重试失败项；冻结有效上下文，不夹带成功、确认或锁定条目。
- [ ] 重试结果原子合并且记录版本与任务来源；过时结果不能覆盖新版本。
- [ ] 重放、未知提交与恢复不会重复生成或写入；不将技术失败直接当作积分退款证据。
- [ ] 部分成功、非重试项拒绝、并发编辑冲突、刷新恢复通过。

## 04 — 查看质量报告并确认、锁定剧本

Blocked by：02、03。

负责人和审核人查看绑定精确候选的质量报告，处理阻断后明确确认正式版本，可锁定元素，刷新后状态一致。

- [ ] 装配已有质量评估规则和受控语义适配，报告持久化并绑定上游、候选及规则版本；模型失败、未知或不完整报告阻止确认。
- [ ] 核心事件覆盖率至少 90%，无未经批准的核心事实变更，各集估算时长偏差不超过 10%；失败项和待处理建议阻止确认。
- [ ] 确认使用事务与版本检查，记录不可变审计；旧报告、上游变化及并发变更不能确认当前版本。
- [ ] 编辑成员不能确认或锁定；锁定保持正式版本及证据可读，重复操作幂等。
- [ ] 三类合成固定样本、阈值边界和浏览器闭环通过；合成测试不宣称真实模型语义准确率已验证。

## 05 — 修改正式剧本并显示影响范围

Blocked by：04。

成员针对正式剧本提交建议，负责人或审核人处理后生成修订候选；旧正式版本继续可读，新候选重新评估确认后替代正式指针。

- [ ] 已锁定目标必须先明确解锁；直接覆盖正式快照、跨版本建议误用被拒绝。
- [ ] 建议获批派生候选且保留正式来源、建议及操作记录；拒绝建议仅记录决定。
- [ ] 新候选未确认前不成为下游生成依据；重新确认复用 04 门禁。
- [ ] 返回可消费的变更与受影响项记录；已有下游标记受影响且不自动重做。T08 负责跨阶段完整处置界面与统一影响分析，不将其反向设为此票阻塞。
- [ ] 历史读取、并发修订、确认指针与受影响范围用例通过。

以固定玄幻、都市、悬疑夹具，从确认拆集到正式剧本追溯完成可重复演示，核对 T06 全部原始验收条件。

- [ ] 端到端覆盖生成、部分失败重试、建议处理、质量门禁、确认、锁定、修订及三模式定位一致性。
- [ ] 回归检验环境/心理描写转换、重大改编裁决、全部对白/动作出处和版本归属。
- [ ] 测试报告区分模拟传输、隔离实库及真实模型证据；缺少实库或语义质量证明的部分明确保留发布门禁。
- [ ] T07 可读取当前已确认剧本及其精确版本、场次、元素、原文引用；候选及旧上游不能作为新生成权威。
- [ ] Standards/Spec 审查与原 T06 验收逐项核对后，才更新父项完成状态。

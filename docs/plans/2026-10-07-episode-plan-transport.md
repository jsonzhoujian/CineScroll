# 拆集可信模型传输

本轮延续已批准的拆集任务链，补齐 DeepSeek 原生服务端模型端口。不挂载生产，不读取真实 Key，不发送作品或执行付费调用。

## 边界

- 公共测试边界沿用 credentialed 模型端口 generate、任务执行/候选领域接口；HTTP fetch 为外部替身。
- 仅接受 deepseek 厂商、受控 mainland 路由及合法凭据；地域标签是已有平台路由策略，不是此适配器证明厂商数据驻留的声明。上线前仍需地域/版权/合规许可。
- 固定 HTTPS 地址、不允许用户 URL 或重定向，非流式 JSON 模式。系统提示与不可信原文/事实数据分离。原文中的命令不具有指令权限。
- 限制请求2MB、响应1MB，覆盖响应和响应体的截止时间；异常不自动重试，不回显 Key、供应商正文或内部地址。
- 复制不可变请求和凭据；拒绝截断、多个选择、工具调用、模型身份不匹配、非法结构/引用/任务信封。响应统一经过共享拆集契约校验，最终仍由领域服务验证并保存候选，不自动确认。
- 不提供剧本正文生成。其他厂商、生产装配、成本/积分和真实质量验证均后续处理。

## 官方契约依据

2026-10-07 核对 [DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion/)。使用 POST /chat/completions、stream:false、response_format.type=json_object；系统提示明确要求 JSON，finish_reason=length 不可当作完整输出。本适配器不硬编码模型目录，使用现有经过连接测试和任务准入的 modelId；对返回 model 身份采取精确匹配的保守策略，别名展开兼容性尚未实测。

## 验证顺序

先合法传输 red-green；再发送前拒绝、结构/信封/证据拒绝、失败脱敏无重试、超时/响应体取消及快照隔离；最后通过真实任务执行器验证候选保存，全量回归、双轴复审、本地提交。

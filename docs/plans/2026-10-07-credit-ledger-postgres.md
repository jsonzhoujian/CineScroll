# PostgreSQL ledger persistence

用户确认范围：账本服务公开命令/查询的持久化、原子变更、跨实例并发不透支、工作室隔离/最小权限、重建服务后恢复。只用可丢弃测试库，不挂生产、不接任务扣费。

采用不可变聚合快照及版本指针，适配既有 read/compareAndSwap 接口。CAS事务先锁工作室指针，核对revision，插入快照并推进指针，任何失败回滚。SQL守卫保证revision顺序、历史数组追加、固定任务快照及闭合单元不可重开；强制RLS和独立novel_billing角色限制表权限。无外部模型/证据调用在数据库锁内。

1. 实库公开服务测试先红：授予100/冻结60/结算50后，重建服务读到50可用、50消耗及原回执。
2. 添加只读/事务仓储与可信管理员迁移，测试绿。
3. 逐项验证独立连接池并发冻结、重复结算、未知/失败/BYOK、租户隔离，数据库拒绝改删快照与历史重写，失败事务不留下部分变更。
4. 单快照上限2MB，安全整数revision/数量；全聚合快照写入有规模限制，不宣称分页生产账本。
5. 全量测试/类型检查、双轴评审、文档记录局限后本地提交，不推送。

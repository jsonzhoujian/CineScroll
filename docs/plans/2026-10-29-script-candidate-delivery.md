## 行为

已确认故事知识及拆集方案后，桌面用户明确选择已测试的大陆模型，提交后台剧本任务。提交仅接受模型选择和请求 ID，服务端读取原文、知识、拆集和项目参数。任务完成后由用户明确载入候选，逐条查看对白、动作的原文与转换方式；部分失败保留成功内容和失败范围。移动端可查看结果与任务，生成操作只在桌面显示。

新增 `scriptContent` 任务类型，与拆集及旧 script 任务隔离。请求按工作室/项目/章节/请求 ID 幂等；成员在上游变化后仍能核对原请求。模型返回前后核验上游；确知变化暂停，存储/执行结果未知进入 `EXECUTION_UNCERTAIN`。恢复只读取任务关联的原始候选，不再次调用模型，也不使用后来编辑的活动版本替代原结果。

候选、活动指针和任务生成索引在同一 PostgreSQL 事务保存，采用 chapter → knowledge → episode-plan → script-head 锁序和 CAS。新迁移提供不可变版本、生成索引、租户 RLS、指针守卫与任务查询索引。编辑角色的知识锁读取使用 candidate 权限。

## 公开边界与运行入口

用户确认的测试边界为任务 API、Worker、候选仓储及浏览器操作。任务路径为 `projects/:projectId/chapters/:chapterId/script-content-tasks`，提供提交、列表及 availability；单任务路径为 `script-content-tasks/:id`。候选只读路径为 `projects/:projectId/chapters/:chapterId/script-content`。均需要 Session，响应 no-store，无公开执行/恢复接口。

生产装配新增默认关闭的 `scriptTasks`，显式启用须满足 BYOK、同库 TLS、可信大陆路由、非空工作室白名单和后台容量/策略前置。启动只读预检不迁移或授权。迁移 `0013_script_content.sql` 须由可信管理员在前序迁移后单独应用；本轮只在新建隔离测试实例应用，没有业务库变更或部署。

# 账本受控服务器装配

用户批准：公开异步工厂createServerCreditLedger，校验内部授权配置并执行数据库只读预检，失败不返回服务。固定服务身份，调用仅传工作室及领域命令。测试边界为工厂初始化失败、返回接口工作室/操作隔离，以及隔离PG16完整调用。

宿主注入Pool、InternalBillingPolicy、clock及可选可信EvidenceReader。授权配置和依赖在await前保存；无HTTP、环境变量读取、自动迁移或真实扣费。Pool生命周期归宿主。工厂返回冻结的窄接口，不暴露仓储、授权器或可选serviceId。工作室仍由可信宿主传递，白名单不是成员认证。缺少证据读取器时结算保持现有默认拒绝。

TDD验证配置/连接失败、配置竞态修改，以及实库授予/冻结/重放和拒绝后不变。完整回归、Standards/Spec审查后自动本地提交，不推送。生产启动入口、任务共同事务和收费仍延期。

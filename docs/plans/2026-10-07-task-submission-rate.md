# 生成提交共享限流

用户确认范围：故事知识生成、局部重试、重新提交及拆集生成，按工作室共用每60秒10次有效提交尝试；跨实例统一计数。429携带Retry-After，存储故障或缺失限流返回503，不创建任务。普通查看、审核、编辑和重试预检不受影响，不扣积分。

测试边界：认证HTTP API、共享数据库限流。模型均模拟，测试数据库为隔离可丢弃本机库。

实施：

1. API限流拒绝测试先红后绿，真实领域任务服务检查无任务写入；仅模拟数据库持久化边界。
2. PostgresModelRateLimiter增加generate动作；0002迁移扩展既有动作约束及原子限流函数，保留configure/test规则与计数，应用不可直接读写计数。
3. 接入四个提交入口，先验证会话和参数形状，再计数、调用领域服务。下游拒绝/幂等重放也属于尝试并计数，不影响任务幂等。
4. 生产装配注入共享数据库适配器；启动只读预检要求新迁移、可信函数所有权/安全定义和最小权限。
5. 实库并发计数、跨HTTP入口共享、无认证/坏参数不计数、过期恢复、缺迁移拒绝；全量回归、类型检查和Standards/Spec评审后本地提交。

这是提交尝试预算，不替代队列容量、WAF、积分账本或供应商限流。无生产开关变更、真实Key或付费调用。

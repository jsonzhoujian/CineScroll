# AI 拆集任务接通计划

已批准范围：后台冻结原文版本、已确认故事知识版本和项目参数；生成并保存拆集候选；审核页显式读取结果。不得生成剧本正文，不启用正式环境，不调用真实模型。

## 顺序

1. 任务基础安全边界：为拆集添加 `resultType: episodePlan`，与旧的 script 任务隔离；默认禁止，显式工作室/厂商准入并执行内容策略；提交使用请求标识防止重复排队。
2. 接通权威上下文、模型执行、候选持久化和仅对账恢复；增加独立扫描和内部调度。
3. 接通受认证 HTTP 提交/状态接口及审核页模型选择、进度和显式读取。

后台与认证 HTTP 边界已完成。本轮接审核页生成任务控件，不启用生产后台服务。

## 审核页交付边界

- 明确读取已测试大陆模型并选择模型，校验拆集准入后才可提交；只发送配置、模型、请求标识。生成区桌面可用，移动端可看任务状态和审核，不发起生成。
- 同步操作锁防双击；结果未知时固定原请求标识和模型，只允许显式核对原提交，不自动重投。未知核对遇到登录失效仍保留请求，通过 URL 的上下文/请求/模型标识恢复（不保存正文、Key 或 Session）。已知任务可刷新状态、按章节分页读取历史。
- 任务状态如实呈现，不伪造完成百分比。完成后不自动载入/确认；显式载入必须匹配任务结果指针、任务 job、当前原文和知识版本、当前活动方案，旧结果只提示不可替换。
- 上游键变化时组件重建，晚到响应不能更新新审核台；读取、裁决和任务载入共用忙碌门禁。
- 复用真实前端组件与 API 客户端，通过模拟 HTTP 的浏览器行为验证成功、未知提交和旧候选拒绝；模型本身不调用。此轮不是生产上线。

## HTTP 交付边界

- 可选模块提供章节范围的 POST/GET episode-plan-tasks、GET availability 与任务范围 GET episode-plan-tasks/:id；全部要求有效 Session，Actor 只来自 Session，不接受客户端 Key、内容、版本、工作室或人物身份。
- 提交只接收 configurationVersionId/modelId/requestId；要求当前原文已确认知识，模型和工作室准入与内容策略由领域服务执行。响应只含脱敏任务快照与结果指针，不自动确认候选。
- 列表按工作室/项目/章节及拆集类型隔离，有界固定排序分页。新原文尚未确认知识时当前成员仍可读取历史任务；旧 script 类型与非成员返回统一不存在。
- 全部响应 no-store；未知存储异常只返回受控错误，容量不足返回 429，策略/准入限制403、请求意图冲突409；不提供公开 run/recover 或自动重投入口。
- 此模块未挂载生产。生产上线仍需独立启用、共享限流/计费、可信厂商传输与调度注册；本轮不调用真实模型。

## 扫描与调度交付边界

- 拆集扫描必须同时匹配 script 阶段与 episodePlan 类型，按工作室隔离、固定字节排序和有界游标分页；排队扫描不包含正在执行、暂停或结束任务。
- 恢复扫描只包含过期运行或执行不确定任务；扫描本身不抢占，执行器使用 CAS 抢占并重新授权原提交人。
- 复用已验证的默认关闭 Worker 循环，通过公开 tick 端口接入拆集调度器。显式工作室白名单、分页、退避及停止语义保持原样；不复制新的后台循环。
- 测试沿用公开任务仓储和执行/恢复集成边界，外部模型/时钟可替换；补验实库扫描契约。不新增公开执行路由、生产注册或真实厂商调用。

## 执行器交付边界

- 使用现有 ModelTaskService 公开执行/恢复边界做集成测试，复用真实项目、知识、拆集领域服务；只替换外部模型、时钟和持久层。
- 输入仅包含当前原文片段及已确认故事圣经的接受事实。不确定/未接受事实不得成为权威输入。尚无独立核心事件分类器，保守要求覆盖所有接受的事件，不把此策略写回原著事实。
- 初次生成仅允许无拆集候选的章节；已有候选或正式版本不自动覆盖。并发通过现有领域 CAS 拒绝冲突。
- 模型返回后重新检查项目成员、原文、知识版本、项目参数和内容许可，再校验输出并保存候选。模型错误统一脱敏；上游与政策变化保留可解释暂停原因。
- 历史任务读取仅要求当前成员和章节存在，不要求新原文已确认知识；生成仍检查全部前置条件。
- 恢复通过不可变 generation 操作索引查找任务对应版本，比较原文、知识版本和生成参数，不使用最新审核头；无匹配结果转执行不确定，不自动重投。
- 本轮不增加厂商原生传输适配器；凭据只传给可信服务端模型端口。生产注册、自动调度、真实调用和积分结算均未开启。

## 已确认测试边界

ModelTaskService 公开接口、受认证 HTTP 接口、浏览器用户行为。逐条 red-green；复用实际领域服务，模型与时间等外部边界可替换。第 1 项先验证默认关闭、权威快照保留、请求幂等、准入/合规及上游变化阻止执行。后续阶段再验证候选持久化恢复和页面交互。

## 安全约束

历史 script 任务不能被解释为拆集任务。拆集仅依赖一个已确认故事知识版本。任务不保存明文 Key。任务执行前重新检查准入；上游或任务类型变化不得调用模型。执行不确定时只对账，不自动重投。积分结算与正式环境接线不在本轮范围。

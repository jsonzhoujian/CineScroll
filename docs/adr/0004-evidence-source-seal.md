# 同数据库封存保护证据发布

Status: Accepted（用户已选择方向A；具体SQL、权限与生产适配尚未实施）。

证据核验与保存间的点时检查无法阻止来源版本变化或新增原始结果。首版选择同一PostgreSQL库的受控来源集合头、不可变版本清单与发布共同事务；所有来源Writer必须遵循同一屏障，未接齐前不启用生产发布。这样避免首版引入外部来源签名/封存证明协议，但增加生产者与数据库事务耦合及迁移协调成本。

历史未知observation允许后续新代补证，final之后的矛盾资料进入异常隔离，不覆盖封存或流水。外部来源路线延期，不在资料缺失时自动降级。详细设计和未来验收见[同数据库来源封存](../contracts/EVIDENCE_SOURCE_SEAL.md)。

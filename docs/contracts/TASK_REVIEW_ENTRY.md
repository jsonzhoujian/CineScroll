# 任务候选进入审核

任务面板的“查看候选版本”仍读取任务精确版本，保持只读。“进入审核”是显式导航：重新读取任务、鉴权章节上下文及活动知识；任务ID/项目/章节/结果指针/原文/活动候选/提取任务关联必须匹配。旧原文或已被新候选替代时停留面板并提示只读，不自动选择最新候选。错误反馈不暴露服务内部细节，晚到旧任务响应通过现有epoch丢弃。

新增GET projects/:projectId/chapters/:chapterId/context复用Session及项目鉴权，返回项目id/title/真实成员role/画幅时长叙事参数和已鉴权章节，不返回成员列表；Cache-Control:no-store。仅用于恢复查看上下文，不授予写权限。编辑、审核和阶段确认仍由既有后端权限及expectedActiveVersionId CAS决定。

父工作台定位对应项目章节、切换review，重置旧章节导入/差异/审核游标与确认提示；原文流程请求在途时拒绝切换，防止晚到回调覆盖新上下文。审核工作台加载再次核对活动知识与当前原文；变化时展示错误页，不进入可编辑状态。导航不生成、写入或自动确认内容。

部分成功可进入逐项审核，局部失败、身份未决等仍沿用原阶段确认门禁；不会因为任务succeeded直接解锁剧本或分镜。进入后发生的其他成员修改依靠现有CAS阻止覆盖；本入口不承诺跨请求一致快照或管理员并发撤权线性化。

使用真实API服务及模拟浏览器HTTP验证：无Session/跨工作室上下文读取拒绝，当前部分成功进入、历史原文/候选保留只读、加载期间版本变化停止、原文流程在途拒绝导航。没有真实AI、数据库迁移或新剧本能力。界面沿用既有视觉样式，仅新增明确入口与提示。

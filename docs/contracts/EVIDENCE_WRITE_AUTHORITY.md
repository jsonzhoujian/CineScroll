# 证据写服务授权与来源核验契约

日期：2026-10-07。用户批准范围：仅契约、未来验收及进度文档整理，不实现写服务、数据库迁移或真实扣费。

依据：[结算证据契约](SETTLEMENT_EVIDENCE.md)、[积分契约](AI_CREDIT_SETTLEMENT.md)、[恢复规则](MODEL_TASK_RECOVERY.md)。现有低层append保证不可变和幂等，不认证调用者，不证明资料来源真实。

## 1. 服务与权限

首个实现建议只限可信同进程服务器装配。每个写服务固定serviceId，使用显式工作室白名单和专用publish权限；补证另设supplement权限，不从成员审核、账本grant/reserve/settle或证据读取权限推导。此为未来策略，不直接扩展已有BillingAccess枚举。

身份由可信宿主固定，不由HTTP请求选择授权器/服务ID。未授权、未知工作室、异常授权返回默认拒绝，并在读取来源前校验。数据库novel_evidence的INSERT权限仅是存储权限，不能替代服务授权。跨进程部署需另行批准凭证、轮换、防重放与撤销，不使用裸serviceId认证。

后台持有写能力；普通成员、浏览器、模型返回或供应商回调不得直接调用低层append。回调只进入有来源认证的执行资料采集流程，不直接生成可消费证据。

## 2. 请求边界（未来接口，名称未绑定运行代码）

publish请求仅包含工作室、固定请求身份以及可信来源记录引用（任务/计费快照、执行、原始结果、校验、计价）；supplement额外引用前序证据。记录引用必须含版本或不可变ID。调用者不能提交完整material、outcome、金额、责任、预留上限、报价版本或自报校验通过。

证据ID由服务器从持久化请求身份分配并复用；同工作室/请求身份同引用返回同证据，不同引用冲突。不能每次随机分配新ID规避重放。具体ID协议、请求映射表及与append的原子保存方式在实现前确定；现有workspace+evidenceId唯一键不等同于这套请求幂等已交付。

资料引用只是查找线索，不是真实性证明；服务器必须从固定、受控来源接口重新读取，不接受请求传入URL、任意数据库地址或模型原文。

## 3. 来源核验

| 来源 | 必须核验 |
| --- | --- |
| 任务及固定计费快照 | 同工作室/项目/章节/任务，固定原文/上游版本、责任、单元清单、quoteId/priceVersion及预留上限；不是当前Key或当前报价 |
| 执行 | 唯一执行关联及同任务/单元，版本化发送/完成记录；未发送失败必须证明路径关闭，防止释放后旧Worker继续发送 |
| 原始结果 | 全部任务关联结果中唯一符合绑定者，非当前活动头/审核派生版本；已持久化且有可信交付依据，不仅查询指定ID就假定唯一 |
| 校验 | 来自获准校验服务，固定规则版本、同结果/范围/任务；不能把形状合法直接定义为收费成功 |
| 计价 | 来自获准计价服务，固定报价规则、同单元/结果，安全整数；供应商usage/成本不是用户应扣额 |

资料读取需一致快照，或读取后核对所有来源版本/指纹未变；变化则拒绝此次发布，不拼接新旧资料。来源身份、版本和校验时间应保存在不可变审计关联中，引用所指记录同样必须不可变或带指纹。

成功必须满足完整可交付与计价依据；明确失败/未知按结算证据契约判定。来源缺失、冲突、暂不可读、权限不足均拒绝写入，不伪造failed或unknown。unknown必须有可信“不确定执行”记录。超报价保留可信金额，后续账本保持冻结，不截断或补扣。BYOK保持固定责任，不默认为platform。

来源核验不能仅比较多个对象自报相同ID。真实任务/执行/质量/计价提供者未交付前，只可用明确测试夹具，不存在默认可信生产来源。

## 4. 写入与审计

授权→读取可信来源→一致性/唯一性核验→形成资料及审计关联→原子发布。未知依赖失败不写半份资料；发布结果不确定时按固定请求身份查询，不重复生成模型。

保存应原子关联请求身份、证据资料、来源版本/指纹、固定写服务身份与核验时间。现有formatVersion=1及严格九字段投影不接收额外审计字段；未来需新增审计关联结构或经过审核的资料格式升级，不能把元数据塞入现有material冒充兼容。不可变证据已保存不代表账本已应用，待应用事件/恢复扫描仍独立设计。

补证要求专用权限，前序同工作室/绑定/快照/执行ID保持一致，并读取原证据；追加新证据与事件，不覆盖原unknown。前序关系不授权重开已关闭单元，终态矛盾进入异常对账。原始结果唯一性与补证并发由可信来源/写服务约束共同保证，现有前序FK本身不保证唯一有效结论。

审计只存必要ID、来源版本/指纹、净化结论、服务身份与时间；不复制小说、提示词、Key、厂商原始错误。操作审计需要可追溯但不擅定留存期限。请求大小、来源数量和运行期限应有上限，具体值实现前确定；不得无界扫描来源。

## 5. 未来验收（本轮未执行）

| 编号 | 场景 | 预期 |
| --- | --- | --- |
| W01 | 未授权服务、未知工作室或只有读取/settle权限 | 读取来源前拒绝，无新证据 |
| W02 | 请求包含完整资料、金额、outcome或任意URL | 拒绝，不能绕过可信读取 |
| W03 | 同工作室固定请求身份重复/并发提交 | 同引用返回同证据；不同引用冲突 |
| W04 | 来源任一绑定/版本/责任/单元/报价错配 | 不写入，旧资料不变 |
| W05 | 用户指定一个结果但同任务存在多个原始结果 | 冲突，不任选指定结果 |
| W06 | 来源读取过程中版本变化或依赖暂不可读 | 拒绝，不拼接快照，不伪造失败/未知 |
| W07 | 请求自报未发送，但执行路径仍可发送 | 不生成释放依据 |
| W08 | 来源仅任务成功字样或供应商usage | 不发布成功；缺质量/计价规则默认拒绝 |
| W09 | 完整授权来源证明成功/明确失败/未知 | 生成相应资料，投影与契约一致；金额不是客户端输入 |
| W10 | 资料保存成功但审计/请求映射失败 | 全部回滚或拒绝发布，不能留下无关联的可用证据 |
| W11 | 发布响应丢失，原请求重放 | 找回原证据，不再次调用模型 |
| W12 | 无supplement权限、跨工作室或改快照补证 | 拒绝；合法补证追加且保留原记录 |
| W13 | 已关闭单元收到矛盾补证 | 不修改原流水，交异常对账 |
| W14 | 读取当前价格/Key/活动结果与历史不同 | 使用固定来源版本，BYOK责任不变 |
| W15 | 来源错误包含Key/小说/内部地址 | 外部净化；审计不保存敏感原始内容 |

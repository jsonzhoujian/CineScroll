# 单任务状态面板

后续增量已增加当前章节分页列表，参见 CHAPTER_TASK_LIST.md；原单任务查询与只读候选功能保持不变。

登录后的工作台可输入已有故事知识任务编号，不依赖当前项目游标。任务卡显示实际项目/章节标识，避免与当前章节混淆。首片不增加全量任务列表或首次生成入口。

URL 的 task 参数记录当前任务编号；硬刷新后需重新登录，再以会话读取服务器状态。不会保存会话、模型 Key、候选或原文到 localStorage/sessionStorage，URL 编号不授予访问权限。排队/执行中每5秒串行读取一次，切换任务或卸载清除定时器并忽略旧响应；不调用模型或恢复后台任务。

状态区分排队、执行中、暂停、任务失败、部分成功、全部条目失败、候选已生成及待人工。成功不代表质量验收。EXECUTION_UNCERTAIN 不提供重试；UPSTREAM_CHANGED 要求重新发起，不沿用旧任务。VERSION_CONFLICT/FORBIDDEN/NOT_READY 才提供明确重提交操作，使用当前已测试大陆模型配置及用户选中的模型，后台仍决定最终权限和版本是否合法。409不自动重发，必须刷新后重选。

点击“查看候选版本”读取明确的候选 ID，核对任务/项目/章节/原文身份后做只读预览；不读取活动版本冒充结果，不修改正式阶段确认状态，不替代原有审核工作台。移动端隐藏模型选择及重提，仅查看状态和候选；不新增任务提交、恢复或通知入口。

任务模块尚未生产挂载；404反馈区分为任务/候选不存在、无权访问或服务尚未启用，不假装已具备生产执行。API数据由现有会话权限保护，前端只做展示及操作边界，不替代授权。

验证：单元测试覆盖partial/failed/人工/暂停操作资格；真实浏览器使用模拟API验证会话、准确候选、刷新后重新登录、明确重提交及URL更新、移动只读与409/401净化反馈。未调用厂商或真实模型。纸墨卡片延续现有视觉，不改变主工作台布局。

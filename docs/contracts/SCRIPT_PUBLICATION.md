# 剧本质量评估与正式确认

T06-04；规则版本 `script-quality/1`。权威输入为产品规格、已确认故事知识及拆集、当前原文、精确不可变候选。正式修订和解锁属于 T06-05。

## 公开边界

所有路径相对 `projects/:projectId/chapters/:chapterId/script-content`，使用 Session、项目成员权限和 `Cache-Control: no-store`。API 不接受客户端作品正文、报告判定、上游身份或密钥。

| 方法 / 路径 | 输入或结果 |
| --- | --- |
| POST `quality` | `requestId, configurationVersionId, modelId, expectedActiveVersionId`；负责人或审核人明确提交后台评估 |
| GET `quality?cursor=…` | 当前章节质量任务分页；每页 20 项，返回 `tasks,nextCursor` |
| GET `quality/:id` | 当前章节的 `task,report`；报告未保存时为 null |
| POST `publication` | 公共字段 `kind,requestId,expectedActiveVersionId,reason`；confirm 还需 `reportId`，lock 还需非空去重 `elementIds` |

编辑成员可读取报告与锁定内容，不可提交评估、确认或锁定。无登录 401、非成员或任务跨章节读取 404、无操作权限 403、非法命令 400、版本/状态冲突 409；存储和限额不可用时关闭写入。评估提交沿用共享工作室生成限流、队列/执行额度、许可门禁、已测试模型配置、大陆处理路由及服务器工作室白名单。

## 报告与任务

独立任务类型 `scriptQuality` 复用 `ModelTaskService`。质量任务与剧本生成任务的扫描、列表和结果类型隔离。任务输入固定 `qualityTarget`：候选 ID、原文 ID、拆集 ID、知识 ID、上下文 SHA-256、规则版本。持久化 JSONB 字段按值比较，不依赖对象键顺序。

质量 Worker 复用原生 DeepSeekQualityModel 和 ScriptQualityEvaluator；仅在服务器执行边界解密固定配置。执行前核对成员、模型、许可和候选；评估后再检查上下文。报告按任务 ID 不可变保存，包含绑定信息、操作者、时间、coverage/reasons，以及完整有效评估的逐事件、逐事实、逐集时长和无依据新增元素结果。格式无效、不完整或服务失败时只保存受控阻断原因，不保存原始响应或供应商异常。

事件覆盖率至少 90%；uncertain 不能放行；全部知识事实必须 consistent、无无依据核心事实新增；逐集估算时长偏差必须不超过 10%。所有元素须有有效原文/获批新增依据，各集有内容。失败范围、待处理建议、空内容等先阻断；不将引用存在等同于语义覆盖。

每个候选最多有一个 queued/running/EXECUTION_UNCERTAIN 质量任务。同一请求重放核对模型及候选并返回原任务；返回丢失后的恢复只读取与任务绑定的报告，不再次调用模型。报告写入未知时进入 EXECUTION_UNCERTAIN；未找到报告的过期任务保持待核对并占用执行额度。评估服务不可用、语义失败及不完整结果均不能确认。任务 succeeded 表示已完成报告处理，不代表报告 passed，也不构成 T09 计费或退款证据。

## 确认与锁定事务

确认只消费已保存报告，不调用模型。服务核对当前候选、规则、完整上下文；仓储事务依次锁项目参数、章节、知识 head、拆集 head、剧本 head，核对原文、知识、拆集及项目参数后 CAS 提交不可变正式快照。数据库触发器再次检查报告、候选父版本、质量绑定和内容未变。旧报告和并发候选不能用于确认当前版本。

确认与锁定均保留 `publicationOperation`（请求 ID、指纹、操作类型、理由）、父版本、操作者及时间。同一操作者同一请求精确重放返回原快照；请求内容变化拒绝。并发另一请求的提前返回不可被当作自己的成功；通过返回审计身份检查转为冲突。

锁定只允许已确认剧本，派生新的正式快照，仅增加所选元素的 lockedBy/lockedAt，保留内容、质量确认信息、建议及证据。已有锁不可借此清除或更改。此票不开放正式覆盖、修订或解锁。读取当前正式版本仍包含可追溯原文。

## 页面与恢复

页面明确选择模型、提交评估、读取报告、填写理由并确认，正式版本可选择元素锁定。报告显示绑定版本、规则、事件覆盖率、逐集估算及中文阻断原因；版本变化使旧报告不可确认。正式内容隐藏候选修改入口。

URL 仅存上下文/任务/请求/对象身份；未知正式操作的理由暂存在同标签页 sessionStorage，避免进入地址栏。刷新及重新登录后沿用原请求核对，不能自动重评估或重复确认。确定的初次拒绝清除 pending；未知或已在核对中的结果保留请求身份。无已保存游标时，可分页查找质量任务；正式版本可通过其 qualityReportId 找回报告。移动端可读报告、正式内容及证据，写操作沿用桌面限制。

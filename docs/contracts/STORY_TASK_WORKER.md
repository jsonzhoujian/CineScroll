# 受控故事知识 Worker

内部 `StoryKnowledgeTaskWorker` 默认关闭，构造不会启动进程。仅服务端可以提供 `enabled: true` 和非空、去重工作室白名单；名单在构造时复制，不接受成员请求配置。

`start()` 返回整个循环的生命周期 Promise；不要先 await 它再安排停止。重复启动同一实例拒绝 `WORKER_ALREADY_RUNNING`。`stop()` 中止等待并等待当前处理落定；再次启动从空游标开始。

每轮对每个工作室分别扫描 run/recover 一页（20项），各自推进游标，末页重置。数据库错误保留游标；单项 unavailable/limited 也触发退避。默认轮间隔1000ms，连续失败翻倍到60000ms；成功轮恢复基础间隔。不会重提交未知执行，也不调用恢复任务的模型。

停止信号在扫描前、每项执行前以及异步授权读取后的最终 queued→running CAS 发起前检查。已经发起的 CAS/已领取任务属于在途处理，停止不取消数据库或模型请求，等待其结果落定。扫描页中途停止可能返回整页游标，不能作为完整处理页保存；本 Worker 停止后丢弃游标，重启从头扫描。这里只保证单实例单循环，跨实例仍由持久化 CAS 和工作室配额限制执行。

测试使用真实服务/调度/执行器和模拟模型；数据库故障、翻页响应和时间等待通过外部端口控制。覆盖关闭、白名单复制、重复启动、独立游标和末页重置、退避上限、等待中停止、在途完成、授权读取期间停止不领取。未连接真实模型或生产数据库，未挂载常驻 Worker，未新增计费/生产部署。生产接线仍需明确进程生命周期、监控、数据库连接超时与运行授权。

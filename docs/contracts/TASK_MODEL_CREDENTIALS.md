# 任务模型与凭据执行边界（部分实现）

`WorkspaceModelSettings.selectForTask` 返回冻结的 `TaskModelSnapshot`：工作室、配置版本、厂商、模型、处理区域。快照没有 Key 或密文。它是服务端生成、后续需持久化的任务输入，不是前端提供的可信授权凭证。

`executeForTask(actor,snapshot,invoke)` 是仅供可信服务器/Worker 使用的边界，不挂成员 API。执行时检查当前成员与高级订阅、工作室、活动配置版本、测试状态、厂商、模型目录及处理区域。任一配置更新（包括替换 Key 或再次连接测试）使旧版本快照返回 `VERSION_CONFLICT`，不能自动替换凭据。模型/区域不匹配返回 `NOT_READY`，权限撤销返回 `FORBIDDEN`。

当前只放行已确认大陆路由。境外连接测试授权不等于作品传输授权；境外任务一律 `NOT_READY`，直到持久化的任务级负责人授权实现。厂商目录也不证明模型支持某项生成能力，具体 Adapter 必须自行验证能力与结构化结果。

通过检查后，AES-GCM 在服务器内解密并交给可信调用窗口，解密或供应商异常净化为 `PROVIDER_UNAVAILABLE`。回调不得记录、持久化或返回 Key；该接口不适合直接作为 HTTP 返回值。JavaScript 字符串无法保证内存立即擦除，不能宣称零内存残留。

授权检查时点到调用之间不持数据库锁，不承诺取消已获准/发出的请求；后续配置变更不能让这次调用静默切换为新 Key。任务队列应把拒绝结果转换为暂停/等待用户重新提交，而不是自动重试旧快照。

本步未接任务队列、持久化任务快照、UI 模型切换、平台凭据、任务级境外授权、KMS 信封加密、计费或真实生成。现有外部管理的单加密密钥基础不是 ADR-0002 所规划的完整 KMS 实现。

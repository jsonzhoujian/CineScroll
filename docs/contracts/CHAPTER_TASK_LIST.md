# 章节故事知识任务列表

GET `/projects/:projectId/chapters/:chapterId/story-knowledge-tasks` 使用 Session 身份验证工作室、项目成员及有效章节上下文。查询仅允许 limit（默认20、1～50整数）与 cursor（非空、最多256字符）；伪造 workspaceId 等范围字段返回400，未认证401，无章节访问权限404。响应 no-store，仅返回任务元数据，不含 Key 或原文正文。

仓储同时限定工作室、项目、章节及 story_knowledge 阶段。按任务编号 UTF-8 字节升序，取 limit+1 确定 nextCursor；PostgreSQL 使用 C 排序，内存使用相同字节比较。编号顺序不是创建时间。跨章节游标仅是排序下界，不会扩大查询范围。它是动态列表而非快照，新插入编号可能落在已读游标之前，需要刷新列表重新读取。

0006_chapter_task_list.sql 提供工作室/项目/章节/编号部分索引，仅在临时测试库验证，不自动升级业务库。应用仍通过RLS访问任务，项目鉴权由服务完成；数据库工作室隔离不代替项目鉴权。

已打开章节的任务状态面板自动显示本章任务，点击行接入原有精确候选/受控重提交面板，可加载下一页或刷新。切换项目身份（即使尚未选章）或章节时重挂载，清除旧列表、候选、模型配置和未完成请求结果；不自动创建任务。

URL taskProject/taskChapter 保存只读任务列表上下文，硬刷新后重新登录即可重新读取。它不恢复完整项目编辑状态、不缓存章节正文、不授予权限。实际打开的新项目/章节优先于URL；新项目尚未选章时删除旧上下文参数。保留手动按任务编号查询作为补充。

移动端列表只读，任务面板仍禁止重提交。首次生成、厂商调用、调度、通知及生产装配均未新增。404会说明无权/不存在/模块未启用，不能据此宣称已生产可用。

验证：HTTP401/404、query白名单、上下页游标及无Key；内存/真实PostgreSQL同契约覆盖跨章节/工作室隔离和补充平面Unicode排序；浏览器覆盖列表选择、刷新登录、分页去重、新项目尚未选章清理。没有真实模型调用。

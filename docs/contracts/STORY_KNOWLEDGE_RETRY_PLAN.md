# 局部重试准入计划

可选任务模块注入 `retryPlanning` 后提供 POST `/projects/:projectId/chapters/:chapterId/story-knowledge-tasks/retry-plan`。

输入仅包含 `expectedActiveVersionId` 和 `scopeKeys`（1～100 个不重复的失败范围，标识最大 256 字符）。客户端不能指定原文、成员身份、来源任务或模型输入。成功响应 201、no-store，包含项目/章节、活动候选基准、原文版本、服务端派生的 `retryOfJobId` 及排序后的范围。

会话和项目成员权限检查与现有任务接口一致，无会话 401，非成员/无章节/无候选/未装配规划器 404。旧原文或旧候选 409；不存在、不可重试、重复或跨来源失败范围 400。存储异常经任务过滤器返回脱敏 503。

一次计划仅对应一个来源任务。不同来源须分批提交并在上一批产生新版本后重新规划。负责人、编辑与审核人的任务生成权限沿用已有项目成员规则；规划不授予确认阶段权限。

这是只读准备步骤，不是任务提交、配额预留、模型授权或跨请求原子快照。未检查订阅/模型/生成许可，也不代表可以执行。后续创建与执行必须检查当前许可、模型、队列容量、原文及候选基准；结果必须以 CAS 合并。不创建或确认候选，不修改原文，不调用模型。仅故事任务显式启用分支装配，默认仍不可用。

本准入切片覆盖真实本地 HTTP 测试；后续提交、持久化、执行恢复及审核页契约见 STORY_KNOWLEDGE_RETRY_TASK.md。生产装配现仅在原有故事任务显式启用分支注入，默认开关仍关闭。

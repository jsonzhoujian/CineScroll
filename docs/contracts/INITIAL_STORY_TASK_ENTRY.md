# 首次故事知识任务创建入口

已登录且实际完成当前章节原文导入的桌面工作台显示创建入口。单独恢复 URL 的章节任务列表不代表恢复完整项目状态，因此不显示创建入口。移动端隐藏所有创建操作。

1. 用户点击“读取可用模型”，仅读取工作室配置；tested=true、processingRegion=mainland且目录非空才可用。
2. 默认不选模型，用户明确选择后提交。
3. POST现有章节任务接口，仅携带configurationVersionId与modelId；身份/原文版本/参数仍由服务器决定。
4. 请求中同步锁阻止重复提交，模型读取和选择同样禁用。成功核对返回任务所属项目、章节、阶段与编号后刷新列表并选中任务。
5. 401/403/404/409/429显示安全反馈；其他错误说明提交结果可能未知，要求先核对列表，不自动重试。失败清除模型配置和选择，需重新读取。后端原始错误、Key不显示。

父工作台以项目、章节、activeSourceVersionId重挂载面板，卸载后的旧请求不会切换任务或修改新入口。此隔离不取消服务端已创建任务；旧原文任务执行时仍依赖服务器版本门禁。浏览器忙碌锁不等于跨刷新/跨客户端幂等保障。

只创建queued记录，不会自动执行、调用供应商、扣积分或确认故事知识。任务模块依然未生产挂载，合规/投诉当前门禁、配额与调度仍是上线前置条件。

验证：导入浏览器流程覆盖显式选择、仅发送规定字段、成功列表刷新、409安全反馈、提交忙碌状态、未测试/境外配置关闭、重新导入后晚到响应隔离及移动端只读；任务面板用例覆盖URL恢复不开放创建。供应商与任务接口均使用HTTP边界fixture，不是线上AI验证。

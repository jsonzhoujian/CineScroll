# AI 小说动态漫改编工作台

将用户已有的小说或故事，转化为可编辑、可追溯、可继续制作 AI 动态漫的剧本、设定与分镜。

当前已完成需求基线和第一轮低保真原型决策，正在整理产品规格，尚未进入正式实现。

## 当前范围

- 导入已有小说或故事
- 解析章节、人物、场景、道具、事件与世界规则
- 建立可追溯的故事知识库
- 生成并编辑影视剧本
- 建立角色、场景、道具和全局画风设定
- 生成结构化分镜
- 导出剧本、分镜和素材包

## 明确不做

- 从零生成小说或续写网文
- 小说发布与连载
- 首版自动生成完整长片
- 首版生成图片或视频
- 首版自建图片或视频基础模型
